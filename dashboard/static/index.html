MADE FOR ANY AGENT

One workspace. Any agent.

Edward, Codex, Claude, Hermes, or another detected agent can use the same terminal map.

  1. Choose its terminal.Each session has its own ID—even two in the same project.
  2. Enable navigation & copy the handoff.Paste it into that agent. It can inspect sessions, focus a terminal, and leave updates.
  3. Close the loop here.Reports show their author and evidence. Proposed prompts wait in Activity for your review.
“Ready” means access is enabled. “Connected” means your agent has checked in. This dashboard does not start an AI worker when you flip the switch.
